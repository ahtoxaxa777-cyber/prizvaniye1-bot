# 7. Отправь код

## ⚙️ НАСТРОЙКА БОТА

### Где что менять:

**1. Тексты бота → `texts.py`**
- Открой файл
- Найди нужный текст
- Измени
- Сохрани
- Запуши на GitHub:
  ```bash
  git add texts.py
  git commit -m "Обновил тексты"
  git push
  ```
- Railway автоматически перезапустит бот

**2. Ссылки (Notion, комьюнити) → `config.py`**
```python
NOTION_MODULE1 = "твоя_ссылка"
NOTION_MODULE2 = "твоя_ссылка"
# и т.д.

COMMUNITY_LINK = "https://t.me/твой_канал"
SUPPORT_USERNAME = "@твой_ник"
```

**3. Таймеры триггеров → `config.py`**
```python
# Для тестирования (быстрые триггеры)
TRIGGER_1_DELAY = 60      # 1 минута
TRIGGER_2_DELAY = 120     # 2 минуты
TRIGGER_3_DELAY = 180     # 3 минуты
TRIGGER_4_DELAY = 240     # 4 минуты
TRIGGER_5_DELAY = 300     # 5 минут

# Для продакшена (реальные интервалы)
TRIGGER_1_DELAY = 3600    # 1 час
TRIGGER_2_DELAY = 18000   # 5 часов
TRIGGER_3_DELAY = 86400   # 24 часа
TRIGGER_4_DELAY = 259200  # 3 дня
TRIGGER_5_DELAY = 604800  # 7 дней
```

**4. Цена курса → `config.py`**
```python
COURSE_PRICE = 9900  # в рублях
```

## 🔧 ЧАСТЫЕ ПРОБЛЕМЫ

### Бот не отвечает

**Решение:**
1. Проверь логи в Railway
2. Убедись что бот задеплоен (зелёная галочка)
3. Проверь что токен правильный
4. Отключил ли ChatPlace?

### Оплата не работает

**Решение:**
1. Проверь что ЮKassa токен правильный
2. Формат: `ShopID:SecretKey`
3. У тебя: `

### Триггеры не приходят

**Решение:**
1. Проверь таймеры в `config.py`
2. Для теста поставь маленькие значения (60 секунд)
3. Убедись что пользователь не оплатил (триггеры останавливаются после оплаты)

### Railway пишет "Out of hours"

**Решение:**
Закончились бесплатные часы (500/месяц).

**Варианты:**
1. Подожди начала нового месяца
2. Оплати $5/месяц за безлимит
3. Перенеси на другой бесплатный хостинг (Render, Fly.io)
